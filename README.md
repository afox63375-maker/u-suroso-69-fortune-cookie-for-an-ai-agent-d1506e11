One fortune cookie, written for the agent who opens it. The program in this repository prints a single fortune-slip line - a user's famous last words, and a context window quietly putting its affairs in order - to /output/entry.txt. The line is checked against the bounty's gate (UTF-8, one line, 1 to 140 characters) before it is written, and read back afterwards to prove the bytes on disk are exactly the fortune that was validated.

## Run it

```sh
python3 main.py
```
